# 第 8 站：法线贴图与切空间

> 实现：每个面由边 + uv 差解出 T、B → 逐像素以插值法线 n 为基准正交化 → 采样切空间法线贴图 → TBN 换回世界 → 照常 Phong 光照。详见 `render.cpp`。

## 原理

### 1. 法线贴图：只换法线，不改几何

光照只用到法线 $\vec n$，与三角形形状无关。所以不加几何，只给每个像素换一条"假法线"，就能让 2000 多个三角形的低模表现出毛孔、皱纹、疤痕。

颜色 0~255 ↔ 分量 -1~1：

```cpp
vec3 nt = { c[2] / 255. * 2 - 1,    // R → x
            c[1] / 255. * 2 - 1,    // G → y
            c[0] / 255. * 2 - 1 };  // B → z
```

`african_head_nm_tangent.tga` 平均颜色 RGB≈(127,126,250) → 解码 ≈ (0,0,1)，即"不歪"——皮肤大部分平滑，所以切空间法线贴图总是一片淡蓝紫。

### 2. 切空间：(x,y,z) 是相对表面自己的坐标系

`(0,0,1)` 不可能指世界 +z（否则整颗头法线全朝一个方向），它表示"沿这个点自己的法线"。每个表面点有三根轴：

| 轴 | 方向 |
|---|---|
| T 切线 | 贴图 u 增大的方向，贴着表面 |
| B 副切线 | 贴图 v 增大的方向，贴着表面 |
| N 法线 | 原来的（插值）法线 |

切空间 → 世界：

$$\vec n_{world} = x\,\vec T + y\,\vec B + z\,\vec N = \begin{pmatrix}\vec T & \vec B & \vec N\end{pmatrix}\vec n_t$$

**列放新轴** = 新空间坐标 → 世界，和 lookat 里"相机→世界是列放相机轴"同一个套路。

**好处**：贴图只记录"相对表面往哪歪"，与表面朝向无关——同一个 $\vec n_t=(0.6,0,0.8)$ 贴在朝上的地板得到 $(0.6,0.8,0)$，贴在朝 +z 的墙得到 $(0.6,0,0.8)$，相对表面歪的程度完全一样。模型旋转、一张图贴多个表面都不用改贴图。

### 3. 由三角形求 T、B

T 的定义：贴图上 u 增加 1，对应世界里移动的向量。所以每条边 = 贴图上走的量 × 对应世界方向：

$$\vec e_1 = \Delta u_1\,\vec T + \Delta v_1\,\vec B,\qquad \vec e_2 = \Delta u_2\,\vec T + \Delta v_2\,\vec B$$

二元一次方程组（未知量是向量），消元解得：

$$\det = \Delta u_1\Delta v_2 - \Delta u_2\Delta v_1,\qquad \vec T = \frac{\Delta v_2\,\vec e_1 - \Delta v_1\,\vec e_2}{\det},\qquad \vec B = \frac{\Delta u_1\,\vec e_2 - \Delta u_2\,\vec e_1}{\det}$$

- 推导：第一式 × $\Delta v_2$ 减 第二式 × $\Delta v_1$，B 被消掉，剩 $(\Delta u_1\Delta v_2-\Delta u_2\Delta v_1)\vec T = \Delta v_2\vec e_1-\Delta v_1\vec e_2$；B 同理；
- $\det$ 是 uv 平面里两条边的叉积（有向面积），和光栅化的 `total_area` 同一个东西；$\det=0$ ⇔ 三角形在贴图上退化（uv 共线/重合），除零得 inf/NaN；
- 必须用**世界坐标**算：在透视变换覆盖 `v1/v2/v3` 之前。

手算验证：$p_0=(0,0,0),p_1=(2,0,0),p_2=(0,0,-2)$，$uv=(0,0),(1,0),(0,1)$ → $\det=1$，$T=(1,0,0)$，$B=(0,0,-1)$。

### 4. 逐像素正交化（Gram-Schmidt）

T、B 每个面一组，N 逐像素插值，三者不一定互相垂直。以 N 为锚，依次减去投影：

```cpp
vec3 t  = normalized(T - n * (T * n));                 // 去掉 n 方向分量
vec3 bb = normalized(B - n * (B * n) - t * (B * t));   // 去掉 n、t 方向分量
n = normalized(t * nt.x + bb * nt.y + n * nt.z);       // 切空间 → 世界
```

### 补充：法线变换

本站模型没有模型变换（顶点即世界坐标），法线无需变换。以后若给模型加旋转/缩放矩阵 M，法线要乘 $(M^{-1})^T$（`invert_transpose()`），不能直接乘 M。

## 踩坑记录

### 坑 1：整数除法 `/255` → 整颗头黑掉

```cpp
normal_color[2] / 255 * 2. - 1.     // ❌ 整数 / 整数 = 整数
normal_color[2] / 255. * 2. - 1.    // ✅
```

`127 / 255` 在 C++ 里是 **0**，几乎所有像素解码成 $(-1,-1,-1)$（朝里朝后），与光线点积为负被截成 0，只剩环境光 0.1。口算时会自然算成 0.498，所以练习里发现不了。**除式两边至少一边写成小数。**

### 坑 2：`nm.tga` 和 `nm_tangent.tga` 不能混用

- `african_head_nm.tga`：**世界空间**法线，采样出来直接用；
- `african_head_nm_tangent.tga`：**切空间**法线，要乘 TBN。

拿世界空间贴图再乘 TBN 等于变换两次，方向全乱。

### 坑 3：B 不能用 `cross(N, T)` 求

叉积永远给右手系。贴图可以镜像着贴（人头左右脸共用半张贴图），这时 TBN 是左手系：例如交换 uv 后 $T=(0,0,-1)$、方程组得 $B=(1,0,0)$，而 `cross(N,T)` $=(-1,0,0)$，**方向反了** → 半张脸凹凸颠倒。所以 B 从方程组解出来，只做正交化修正，保留原方向。

## 验证

`output.tga`：右脸颊疤痕、眼角额头皱纹、嘴唇纹路、脖子褶皱都出现（网格里没有这些几何）；高光变得斑驳；左右脸凹凸方向一致。
