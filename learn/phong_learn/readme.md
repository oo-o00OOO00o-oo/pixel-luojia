# 第 7 站：Phong 光照 + 高光贴图

> 实现：插值法线 → 逐像素算 环境光 + 漫反射 + 高光 → 颜色 × 光照并截断。详见 `render.cpp`。

## 原理

$$I = k_a + k_d\max(0,\ \vec n\cdot\vec l) + k_s\max(0,\ \vec r\cdot\vec v)^{s}, \qquad \vec r = 2(\vec n\cdot\vec l)\vec n - \vec l$$

- **环境光** $k_a=0.1$：背光面不再纯黑；
- **反射向量** $\vec r$：$\vec l$ 沿法线的分量保留、垂直分量取反（"镜像"）；$\vec n,\vec l$ 是单位向量时 $\vec r$ 自动是单位向量；
- **高光指数** $s = 5 + \text{spec}$：spec 从 `african_head_spec.tga`（单通道灰度，取 `[0]`，范围 0~174）采样；s 越大高光越小越尖（$0.8^1=0.8$，$0.8^{10}\approx0.1$，$0.8^{50}\approx10^{-5}$）;
- **视线方向** $\vec v$：本站简化为常量 `normalized(eye - center)`，精确做法是逐像素插值世界坐标再算 `eye - P`。

### Gouraud → Phong 着色

| | Gouraud（第 5 站） | Phong（本站） |
|---|---|---|
| 顶点上 | 算好亮度 | 只带法线 |
| 面内插值 | 亮度 | 法线（插值后**重新归一化**） |
| 光照计算 | 每顶点一次 | 每像素一次 |

**为什么 Gouraud 做不出集中高光**：先求值再插值——三个顶点高光都 ≈0，插值出的面内全是 0，面中央那个对齐的峰值根本没机会被算出来。Phong 是先插值再求值，每个像素用自己的法线算 $\vec r\cdot\vec v$，峰值能冒出来。

## 踩坑记录

### 坑 1：代码写进了上一站的目录

开新站后编辑器里还开着 `texture_learn/render.cpp`，代码全写到了旧文件里，而编译运行的是 `phong_learn` —— 结果"没有亮斑"。
**开新站先确认编辑器打开的是新目录下的文件。**

### 坑 2：编译失败时跑的还是旧程序

编译报错不会生成新的 `test`，旧的可执行文件还在，照样能运行、照样输出图片。
**输出图没变化时，先回头看编译那一步有没有 error。**

### 坑 3：颜色 × 光照必须截断到 255

加了环境光和高光后 $I$ 可能大于 1，`200 × 1.5 = 300` 强转 `unsigned char` 会回绕成 `300 − 256 = 44`——**高光最亮的中心反而变成黑斑**。

```cpp
unsigned char cr = min(255., color[2] * I);
```

之后叠加阴影、AO 等多个光照项时同样要截断。
