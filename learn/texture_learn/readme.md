# 第 6 站：纹理贴图

> 实现：插值 uv → 采样 diffuse 贴图 → 颜色 × 亮度。详见 `render.cpp`。

## 踩坑记录

### 坑 1：TGAColor 按 BGRA 顺序填，红蓝写反皮肤发蓝

`TGAColor` 内部是 `bgra[4]` 数组，**第一个分量是蓝、第三个才是红**。采样/组装颜色时按 B、G、R 顺序填；写反的后果：人脸皮肤整体偏蓝（R 和 B 通道互换）。

### 坑 2：v 坐标要翻转

obj 的 `vt` 约定 **v=0 在图片底部**；而贴图读进内存后（TGAImage 加载时做了垂直翻转），**y=0 在顶部**。两个坐标系方向相反，采样前必须翻转：

```cpp
v = 1.0 - v;
```

不翻的后果：纹理上下颠倒，五官错位（眉毛贴到下巴上）。

## 验证

`output.tga`：斜视角人头，肤色、红唇、眼白位置正确。
