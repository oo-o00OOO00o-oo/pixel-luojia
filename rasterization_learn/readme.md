# Lesson 2: 三角形填充 (Triangle Rasterization)

## 核心思路：包围盒 + 边函数

判断像素是否在三角形内，不用纠结"哪条边在左、哪条在右"，改用**叉积符号判断**:

1. 求出三角形的最小包围盒 (bounding box)，只遍历盒内像素；
2. 对每个像素 P，分别计算三条边的叉积：

```
a = (bx-ax)*(py-ay) - (by-ay)*(px-ax)   // AB × AP
b = (cx-bx)*(py-by) - (cy-by)*(px-bx)   // BC × BP
c = (ax-cx)*(py-cy) - (ay-cy)*(px-cx)   // CA × CP
```

3. 三者**同号**（全 ≥0 或全 ≤0）→ P 在三角形内。用"或"条件可同时兼容顺时针/逆时针两种顶点绕序。

> 这正是 GPU 硬件光栅化使用的 edge function 思路。三个叉积的物理意义是**三个子三角形有向面积的 2 倍**，归一化后即为重心坐标 (barycentric coordinates)，后续插值 z / 颜色 / 纹理全靠它。

## 背面剔除 (Back-face Culling)

直接按文件顺序画所有三角形，背面的三角形会盖住正面（无隐藏面消除）。一行修复：

```cpp
if ((x2-x1)*(y3-y1) - (y2-y1)*(x3-x1) <= 0) continue;  // 有向面积 ≤ 0 → 背面，跳过
```

原理：模型顶点绕序一致（如正面看均为逆时针），投影后朝前的三角形保持绕序，朝后的翻转，有向面积的符号即朝向。

**局限**：只解决"朝向"，同向三角形仍是"谁后画谁赢"（如口腔内部盖住嘴唇）→ 需 z-buffer 彻底解决。

## 退化三角形保护

重心坐标计算要除以总面积，面积为零会除零。由于屏幕坐标是整数，有向面积（2倍）也是整数：

```cpp
if (total_area < 1) return;   // 整数语义 = <= 0，同时拦掉背面(<0)和退化(=0)三角形
```

## 踩过的坑

| 现象 | 原因 |
|---|---|
| 三角形颜色不对 | TGAColor 是 **BGRA** 顺序，红色应为 `{0,0,255,255}` |
| 输出全黑 | 在源码目录里运行程序，相对路径 `obj/...` 找不到模型（路径按**运行目录**解析）→ 加载文件务必检查 `ifstream` 是否打开成功 |
| rand 颜色每次相同 | 未调用 `srand`；调试期保持固定反而便于对比 |
| `iss >> idx` 解析 f 行死循环 | 行尾无空格，`peek() != ' '` 永远成立；内层循环需加 `iss.good()` 判断 |
